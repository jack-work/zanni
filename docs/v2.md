# zanni2 (v2)

v1 (boil, gesso, parla, ...) is **frozen**: figar.org keeps working. v2 lives in `assets/v2/`, prefixes its classes
`z2-`, and extends the same `--z-*` token names.

| file | what |
|---|---|
| `tokens.json` | the ONE source: colours per theme as `[light, dark]`, type scale, spacing, the data-viz palette, measure, radius |
| `z2-tokens.css` | GENERATED by `bin/z2-build`: `--z-*` (via `light-dark()`), `--z-fs-*`, `--z-space-*`, `--z-series-1..8`, `--z-seq-1..7`, `--z-div-1..9` |
| `z2-vega-theme.json` | GENERATED: a Vega-Lite `config` per theme x scheme (`band-light`, `band-dark`, `figaro-light`, `figaro-dark`) |
| `z2.css` | page ground (the header is proscenio's), panel (a container), KPI tiles, data table (tabular figures, sticky head, sort affordance), sparkline |
| `z2.js` | `z2.state` (deep-link state in the URL), `z2.kpi`, `z2.spark`, `z2.sortable` (sort order lives in the URL) |
| `z2-chart.js` | `z2.chart(host, opt)`: an interactive stacked-bar chart over EVENTS (one row per thing that happened), aggregated in the browser: unit, interval, range, split and per-interval/running-total toggles (radiogroups, arrow keys), legend that hides series, a hover/keyboard tip that pins on click or Enter and lists the events in a bin, an optional dashed target. Load after `z2.js`. Toggles that cannot apply (under 2 or over 400 bins) are disabled; every choice is in the URL under `<id>.u/.i/.r/.s/.m/.h`. Height = width / phi^2, clamped 220-420 px. |

## The programme layout (z2.css)
A page of many panels (minister-control, the regiment dashboards) wears these on its column:
- `.z2-wide`: the viewport less a gutter (`--z-gutter`), no reading-width cap; prose keeps `--z-measure` inside.
- `.z2-flow`: panels in DOM order, each a full row, except an adjacent `.z2-major` + `.z2-minor` pair, which shares a row at phi : 1
  (minor first: 1 : phi) once the flow is 76rem wide. Three tracks 1 : 1/phi : 1 make both splits one template.
- `.z2-seps`: a separator in the gap between consecutive panels (a hairline fading at both ends, an accent lozenge).
- `.z2-cards`: each panel a card (ground-2, rule border, accent top edge, soft shadow) on the page ground.
- `.z2-textured`: the ground as linen (a weave and a grain from `--z-ink` at 2.5-7%): it never moves a contrast ratio
  measurably, and it follows the scheme because it is mixed from the ink.
- `.z2-golden` (`.z2-golden-rev`): inside a panel, the first two children side by side at phi : 1 (1 : phi) once the panel is
  56rem wide; stacked below that.

**Themes, not forks:** `data-theme="band"` (default; readable, data-dense) and `data-theme="figaro"` (the v1 look).
**Schemes:** `color-scheme` decides; `data-scheme="light|dark"` pins one.

## The contrast law (bin/z2-build --check, also run by test/v2.test.js)
In BOTH schemes and BOTH themes: every text token >= 4.5:1 on `--z-ground` and `--z-ground-2` (WCAG AA);
`--z-on-accent` on `--z-accent` >= 4.5:1; every series colour >= 3:1 on both grounds (WCAG 1.4.11); any two series
>= 0.07 apart in OKLab. A failing token fails the build and names itself; `--report` prints every ratio.

## Consumers
- cheroot-style (the cheroot site + report kit): `tools/sync-zanni` inlines `z2-tokens.css` between markers, stamped
  with the zanni commit, and refuses a zanni whose check fails.
- Never vendor Michelangelus here: zanni is public. A consumer names it in its own `--z-font`.

## Rules for a v2 component
Colours only through tokens; sizes only through `--z-fs-*` / `--z-space-*`; respond to the container, not the viewport;
no innerHTML; an example in `examples/v2.html`; a test in `test/v2.test.js` with a negative control.
