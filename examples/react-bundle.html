zanni-react, no build step

This page imports zanni-react from /zanni/react/0.33.11/index.js through an import map and runs react-bundle.js as a module. React, react-dom and figaro-forms are the page's own same-origin files under /vendor. The import map is inline, so the Content-Security-Policy names its sha256; change the map and the hash must change with it. See docs/react.md.
